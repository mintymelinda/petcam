Timelapse

Loading timelapse status…

Use a local folder under /var/lib/petcam, or mount an SMB/NFS share at /mnt/petcam-network and choose a folder beneath it. Network shares must be mounted by Linux first; see the Timelapse storage instructions. Captures pause if the network mount is not mounted rather than falling back to the SD card.

Frames reuse the active MJPEG stream, so timelapse does not open another camera process. Optional resizing/re-encoding is performed only after a frame is received.
